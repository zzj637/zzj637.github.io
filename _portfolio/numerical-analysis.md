<p>Assignments and the final exam for the Numerical Analysis course (2026, Nanjing University). Each one pairs a Python implementation with a LaTeX report: problem statement, algorithm and derivation, numerical results, and an analysis of the error behaviour.</p>

<p>Topics covered include floating-point arithmetic and numerical stability, Lagrange/Newton/piecewise interpolation, and composite quadrature rules.</p>

<p>Every assignment folder holds the source (<code>.py</code>), the report (<code>.tex</code> and the compiled <code>.pdf</code>), and the figures used in the report.</p>

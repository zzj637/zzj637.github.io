<p>Write-ups and code from the Numerical Analysis course (2026, Nanjing University). Each assignment pairs a Python implementation with a LaTeX report: problem statement, algorithm and derivation, numerical results, and an analysis of the error behaviour.</p>

<p>Topics covered include:</p>

<ul>
  <li><strong>Floating-point arithmetic</strong> — binary representation, machine epsilon, underflow and overflow, and the numerical stability of three different ways of computing the same quantity.</li>
  <li><strong>Interpolation</strong> — Lagrange and Newton forms, and piecewise linear interpolation.</li>
  <li><strong>Numerical integration</strong> — composite trapezoid and Simpson rules, and why the error stops improving once the mesh is refined far enough.</li>
</ul>

<p>Every assignment folder holds the source (<code>.py</code>), the report (<code>.tex</code> and the compiled <code>.pdf</code>), and the figures used in the report.</p>

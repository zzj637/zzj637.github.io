第一部分 · 经典梯度优化器

经典优化算法 · 原理与实现

梯度下降用局部二次模型选步长。SGD 用样本估计梯度，动量利用历史位移，Adam 为每个坐标调整步幅。

1. 梯度下降与局部二次模型

设 F(x)F(x) 是训练目标。若 ∇F\nabla F 是 LL-Lipschitz 的，沿位移 dd 积分可得二次上界。

F(x+d)≤F(x)+⟨∇F(x),d⟩+L2‖d‖22.F(x+d)\le F(x)+\langle\nabla F(x),d\rangle+\frac{L}{2}\lVert d\rVert_2^2.

对上界关于 dd 求最小值，再代回最优位移，得到更新和下降量。

xt+1=xt−1L∇F(xt),F(xt+1)≤F(xt)−12L‖∇F(xt)‖22.x_{t+1}=x_t-\frac1L\nabla F(x_t),\qquad F(x_{t+1})\le F(x_t)-\frac1{2L}\lVert\nabla F(x_t)\rVert_2^2.

若 FF 有下界，累加下降量可控制平均梯度平方范数。对凸目标，距离递推给出函数差 F(xt)−F⋆=O(1/t)F(x_t)-F^\star=O(1/t)。对 μ\mu-强凸目标，函数差按 1−μ/L1-\mu/L 的因子收缩。

考虑一个二维二次函数。

F(x)=12(x12+100x22),∇F(x)=(x1,100x2).F(x)=\frac{1}{2}(x_1^2+100x_2^2),\qquad \nabla F(x)=(x_1,100x_2).

2. SGD 与小批量

令经验风险 F(x)=n−1∑i=1nfi(x)F(x)=n^{-1}\sum_{i=1}^n f_i(x)。按每次更新使用的样本数，可分为三种方法。

方法 每步梯度 主要代价
全批量 GD 在同一参数点计算所有样本梯度并求均值 一步开销随数据集规模增长
单样本 SGD 取一个随机样本的梯度 每步成本低，方差较大
小批量 SGD 取 BB 个样本的梯度均值 多算样本以降低方差，可并行计算

𝔼[‖gt−∇F(xt)‖22∣xt]≤σ2B.\mathbb E[\lVert g_t-\nabla F(x_t)\rVert_2^2\mid x_t]\le \frac{\sigma^2}{B}.

对无约束、光滑非凸目标，设 F⋆F^\star 为下界。取 η≤1/L\eta\le 1/L，将小批量更新代入第 1 节的下降上界。

3. Momentum 与 Nesterov

Heavy-ball 的位移递推

令 dt=xt−xt−1d_t=x_t-x_{t-1}，重球动量沿用上一步位移。

dt+1=γdt−η∇F(xt),xt+1=xt+dt+1.d_{t+1}=\gamma d_t-\eta\nabla F(x_t),\qquad x_{t+1}=x_t+d_{t+1}.

旧梯度的权重按 γ\gamma 的幂衰减。同向梯度累积，交替变号的梯度部分抵消。对曲率为 λ\lambda 的一维二次函数，递推式为

xt+1=(1+γ−ηλ)xt−γxt−1.x_{t+1}=(1+\gamma-\eta\lambda)x_t-\gamma x_{t-1}.

当特征多项式 z2−(1+γ−ηλ)z+γz^2-(1+\gamma-\eta\lambda)z+\gamma 的根都在单位圆内时，迭代收敛到零。

Nesterov 的外推点

Heavy-ball 在 xtx_t 计算梯度。Nesterov 在外推点 yt=xt+βt(xt−xt−1)y_t=x_t+\beta_t(x_t-x_{t-1}) 计算梯度，用外推位置的斜率修正位移。

对确定性光滑凸目标，初始化 x0=y0x_0=y_0、q0=1q_0=1，按以下公式递推。

xt+1=yt−1L∇F(yt),qt+1=1+1+4qt22,x_{t+1}=y_t-\frac1L\nabla F(y_t),\qquad q_{t+1}=\frac{1+\sqrt{1+4q_t^2}}2,
βt=qt−1qt+1,yt+1=xt+1+βt(xt+1−xt).\beta_t=\frac{q_t-1}{q_{t+1}},\qquad y_{t+1}=x_{t+1}+\beta_t(x_{t+1}-x_t).

令 zt=qtyt−(qt−1)xtz_t=q_ty_t-(q_t-1)x_t，则 zt+1=zt−qt∇F(yt)/Lz_{t+1}=z_t-q_t\nabla F(y_t)/L。把函数下降量与平方距离变化相加，梯度交叉项抵消。由 qt(qt−1)=qt−12q_t(q_t-1)=q_{t-1}^2（t≥1t\ge1），得到单调不增的势函数。

Φt+1=qt2L(F(xt+1)−F⋆)+12‖zt+1−x⋆‖22.\Phi_{t+1}=\frac{q_t^2}{L}(F(x_{t+1})-F^\star)+\frac{1}{2}\lVert z_{t+1}-x^\star\rVert_2^2.

qt≥(t+2)/2q_t\ge(t+2)/2，因此输出点满足 F(xt)−F⋆≤2L‖x0−x⋆‖22/(t+1)2F(x_t)-F^\star\le 2L\lVert x_0-x^\star\rVert_2^2/(t+1)^2（t≥1t\ge1）。

4. AdaGrad、RMSProp 与 Adadelta

在稀疏特征或嵌入表中，各坐标的梯度出现频率不同。自适应方法用正对角矩阵 HtH_t 调节每个坐标的步幅。

mind{⟨gt,d⟩+12ηd⊤Htd},d=−ηHt−1gt,\min_d \left\{\langle g_t,d\rangle+\frac{1}{2\eta}d^\top H_t d\right\},\qquad d=-\eta H_t^{-1}g_t,

对角元素越大，该坐标的步幅越小。下文的梯度平方、除法和最大值均按坐标计算。ϵ>0\epsilon>0 用于稳定分母。

AdaGrad 累计平方梯度

st=st−1+gt2,xt+1=xt−ηgtst+ϵ.s_t=s_{t-1}+g_t^2,\qquad x_{t+1}=x_t-\eta\,\frac{g_t}{\sqrt{s_t+\epsilon}}.

若两个坐标的当前梯度均为 1，平方梯度累计量为 100 和 1，忽略 ϵ\epsilon 后，步幅分别为 0.1η0.1\eta 和 η\eta。当 st>0s_t>0 时，下面的不等式累加后只剩首尾，可用于推导在线凸优化的遗憾界。

gt2st=st−st−1st≤2(st−st−1).\frac{g_t^2}{\sqrt{s_t}} =\frac{s_t-s_{t-1}}{\sqrt{s_t}} \le 2(\sqrt{s_t}-\sqrt{s_{t-1}}).

累计量保留早期大梯度的影响，后续步幅因此偏小。

RMSProp 平滑平方梯度

vt=ρvt−1+(1−ρ)gt2,xt+1=xt−ηgtvt+ϵ.v_t=\rho v_{t-1}+(1-\rho)g_t^2,\qquad x_{t+1}=x_t-\eta\,\frac{g_t}{\sqrt{v_t+\epsilon}}.

当平方梯度持续低于 vtv_t，移动平均会下降，步长系数随之回升。记忆跨度约为 1/(1−ρ)1/(1-\rho) 个更新步。

Adadelta 平滑梯度与位移

用 vtv_t 平滑平方梯度，用 utu_t 平滑平方位移。

vt=ρvt−1+(1−ρ)gt2,dt=−ut−1+ϵvt+ϵgt,ut=ρut−1+(1−ρ)dt2.v_t=\rho v_{t-1}+(1-\rho)g_t^2,\qquad d_t=-\frac{\sqrt{u_{t-1}+\epsilon}}{\sqrt{v_t+\epsilon}}g_t,\qquad u_t=\rho u_{t-1}+(1-\rho)d_t^2.

参数更新为 xt+1=xt+dtx_{t+1}=x_t+d_t。原始形式用截至上一步的位移 RMS 代替显式全局学习率。

5. Adam 及其变体

Adam 的矩估计与偏差修正

初始化 m0=v0=0m_0=v_0=0，从 t=1t=1 开始更新。

mt=β1mt−1+(1−β1)gt,vt=β2vt−1+(1−β2)gt2,m_t=\beta_1m_{t-1}+(1-\beta_1)g_t,\qquad v_t=\beta_2v_{t-1}+(1-\beta_2)g_t^2,
m^t=mt1−β1t,v^t=vt1−β2t,xt+1=xt−ηtm^tv^t+ϵ.\widehat m_t=\frac{m_t}{1-\beta_1^t},\qquad \widehat v_t=\frac{v_t}{1-\beta_2^t},\qquad x_{t+1}=x_t-\eta_t\frac{\widehat m_t}{\sqrt{\widehat v_t}+\epsilon}.

mtm_t 是梯度的移动平均，vtv_t 是平方梯度的移动平均。若梯度恒为 gg，从零初始化得到 mt=(1−β1t)gm_t=(1-\beta_1^t)g。偏差修正补回初期缺失的权重，平方梯度同理。忽略 ϵ\epsilon，第一步在非零梯度坐标上的更新为 −η1sign(g1)-\eta_1\operatorname{sign}(g_1)。

Nadam 的分子

Nadam 用当前梯度和修正后的动量替换 Adam 的分子 m^t\widehat m_t。

β1m^t+1−β11−β1tgt.\beta_1\widehat m_t+\frac{1-\beta_1}{1-\beta_1^t}g_t.

AdaMax 的衰减最大值

分子为 m^t\widehat m_t，分母改为 ut+ϵu_t+\epsilon，其中 ut=max(β2ut−1,|gt|)u_t=\max(\beta_2u_{t-1},\lvert g_t\rvert)。某次梯度尖峰成为最大值后，其贡献每步乘 β2\beta_2，直到被新梯度超过。

AMSGrad 的历史最大值

Adam 的二阶矩下降时，固定学习率下的坐标步长系数会回升。AMSGrad 维护 v¯t=max(v¯t−1,vt)\bar v_t=\max(\bar v_{t-1},v_t)，用 v¯t\sqrt{\bar v_t} 定标。历史最大值单调不减，使分析可以控制跨步的度量变化。

AdamW 的解耦权重衰减

在普通 SGD 中，把 λxt\lambda x_t 加入梯度等价于直接将参数乘 1−ηtλ1-\eta_t\lambda。Adam 的矩估计会吸收加入梯度的正则项。AdamW 用损失梯度更新矩估计，并单独缩放参数。

xt+1=(1−ηtλ)xt−ηtm^tv^t+ϵ.x_{t+1}=(1-\eta_t\lambda)x_t-\eta_t\frac{\widehat m_t}{\sqrt{\widehat v_t}+\epsilon}.

6. 二维二次函数实验

起点为 (4, 1)，Heavy-ball 动量为 0.8。选择步长与迭代次数，查看函数值。

GD Heavy-ball Nesterov

在第 1 节的二次函数上，三种方法都从 (4,1)(4,1) 出发，取 η=1/100\eta=1/100。Heavy-ball 取 γ=0.8\gamma=0.8，Nesterov 用第 3 节的调度。代码输出各方法的迭代坐标和函数值。

from math import sqrt


def loss(x):
    return 0.5 * (x[0] ** 2 + 100 * x[1] ** 2)


def trace(method, steps=80, eta=0.01, gamma=0.8):
    x = prev = y = (4.0, 1.0)
    q = 1.0
    yield x
    for _ in range(steps):
        query = y if method == "Nesterov" else x
        g = (query[0], 100 * query[1])
        nxt = tuple(query[j] - eta * g[j] for j in range(2))
        if method == "Heavy-ball":
            nxt = tuple(nxt[j] + gamma * (x[j] - prev[j]) for j in range(2))
        if method == "Nesterov":
            q_next = (1 + sqrt(1 + 4 * q * q)) / 2
            beta = (q - 1) / q_next
            y = tuple(nxt[j] + beta * (nxt[j] - x[j]) for j in range(2))
            q = q_next
        prev, x = x, nxt
        yield x


for name in ("GD", "Heavy-ball", "Nesterov"):
    history = list(trace(name))
    for t in (1, 10, 40, 80):
        a, b = history[t]
        print(f"{name:10s} step={t:2d} x=({a:+.4f}, {b:+.4f}) F={loss(history[t]):.6f}")

步长为 0.010 时，GD 第一步将高曲率坐标归零，低曲率坐标每步乘 0.99。Heavy-ball 第一步也将高曲率坐标归零，第二步受动量影响越过零点。步长改为 0.015 后，GD 收敛，这套 Nesterov 递推发散。

第二部分 · EMA 与 Nesterov 外推

从指数移动平均到参数外推

指数移动平均（Exponential Moving Average，EMA）用一个递推值平滑连续观测。每来一个新值，就把它与上一次的平均值按比例混合。第一篇的 Adam 用它平滑梯度，EMA-Nesterov 用它平滑参数位移。

1. 什么是 EMA

设 ztz_t 是第 tt 次观测，sts_t 是平滑后的值。给定初值 s0s_0 和平滑系数 0≤γ<10\le\gamma<1，每次更新为

st=γst−1+(1−γ)zt.s_t=\gamma s_{t-1}+(1-\gamma)z_t.

例如，取 γ=0.8\gamma=0.8、s0=10s_0=10。观测先到 15，再到 5。EMA 先更新为 0.8×10+0.2×15=110.8\times10+0.2\times15=11，再更新为 0.8×11+0.2×5=9.80.8\times11+0.2\times5=9.8。

展开递推可以看到每个历史观测的权重。

st=γts0+(1−γ)∑j=1tγt−jzj.s_t=\gamma^t s_0+(1-\gamma)\sum_{j=1}^{t}\gamma^{t-j}z_j.

简单移动平均对窗口内的观测赋予相同权重。EMA 中观测每早一步，权重就再乘一次 γ\gamma。γ=0.8\gamma=0.8 时，最近三次观测的权重分别是 0.20、0.16 和 0.128。每次更新只需保存上一次的平均值。

平滑与滞后

γ\gamma 越大，新观测的权重越小，曲线越平滑，跟随趋势变化也越慢。若观测在 +a+a 和 −a-a 之间交替，稳态下 EMA 的振幅为原来的 (1−γ)/(1+γ)(1-\gamma)/(1+\gamma)。按稳态权重计算，历史观测平均距今 γ/(1−γ)\gamma/(1-\gamma) 步。γ=0.995\gamma=0.995 时，这个平均距离是 199 步。

2. Nesterov 与其他外推方法

经典 Nesterov：在外推点求梯度

记 dt=xt−xt−1d_t=x_t-x_{t-1}。重球动量在 xtx_t 求梯度，再加上位移项 βtdt\beta_t d_t。Nesterov 先沿位移外推，再在 yty_t 求梯度。

yt=xt+βtdt,xt+1=yt−ht∇f(yt).y_t=x_t+\beta_t d_t,\qquad x_{t+1}=y_t-h_t\nabla f(y_t).

对 LL-光滑凸目标，取精确梯度、ht=1/Lh_t=1/L 和 βt=t/(t+3)\beta_t=t/(t+3)，函数差上界为 O(T−2)O(T^{-2})。在小批量训练中，外推会把单步位移中的振荡带进查询点。

Lookahead：对内循环的起点和终点做插值

从慢参数 ϕt−1\phi_{t-1} 出发，基础优化器连续走 KK 步，到达快参数 θt,K\theta_{t,K}。再更新慢参数。

ϕt=(1−a)ϕt−1+aθt,K,0<a<1.\phi_t=(1-a)\phi_{t-1}+a\theta_{t,K},\qquad 0<a<1.

新慢参数位于起点和终点之间，并作为下一轮的起点。KK 步的位移之和决定慢参数的更新方向。

NALA：内循环结束后再做一次梯度更新

从 ϕt−1\phi_{t-1} 运行 KK 步，得到快参数 θt,K\theta_{t,K}。用整段位移构造查询点 yty_t，再做一次外层梯度更新。

yt=θt,K+μN(θt,K−ϕt−1),ϕt=yt−a∇f(yt).y_t=\theta_{t,K}+\mu_N(\theta_{t,K}-\phi_{t-1}),\qquad \phi_t=y_t-a\nabla f(y_t).

μN>0\mu_N>0 时，查询点越过终点。−1<μN<0-1<\mu_N<0 时，查询点位于起点和终点之间。NALA 实验采用的 μN=−0.5\mu_N=-0.5 对应中点。

SNOO：对每段内循环的位移加动量

令 FtF_t 表示连续 KK 次基础更新。由外层参数 wtw_t 出发，内循环终点为 ut=Ft(wt)u_t=F_t(w_t)，伪梯度 st=wt−uts_t=w_t-u_t。初始化 b−1=0b_{-1}=0，每段更新一次外层动量。

def ema_nesterov(x, base_step, betas, gamma):
    momentum = 0.0
    for t, beta in enumerate(betas):
        y = x + beta * momentum
        x_next = base_step(y, t)
        momentum = gamma * momentum + (1 - gamma) * (x_next - x)
        x = x_next
    return x


def gradient_step(y, t):
    return y - 0.1 * y

第三部分 · Muon 系列与重尾噪声

AdamW 按元素调整更新幅度。Muon 把整张权重矩阵放在一起处理，调整的是矩阵动量的奇异值。这个区别决定了 Muon 怎么更新、为什么需要矩阵乘法，以及怎样在多张卡上做分片。

1. Muon 的来源、递推与工程实现

Muon 为什么处理奇异值

Keller Jordan 等在 2024 年的 NanoGPT 提速工作中推出 Muon，全名是 MomentUm Orthogonalized by Newton–Schulz。他们观察到，Transformer 的矩阵更新往往集中在少数奇异方向。Muon 从 SGD 动量出发，缩小更新中各奇异方向的幅度差距。

假设动量矩阵是 B=diag(12,1)B=\operatorname{diag}(12,1)。直接用动量更新，两个方向的幅度比是 12 比 1。Muon 对应的理想变换把它改成 diag(1,1)\operatorname{diag}(1,1)。对一般矩阵，先写成奇异值分解 B=UΣV⊤B=U\Sigma V^\top，保留非零奇异值对应的左右奇异向量，再令 Q=UV⊤Q=UV^\top。这相当于把保留下来的奇异值都设成 1。QQ 称为极因子。

为什么用谱范数约束

对线性层 WxWx，权重变化 DD 会让输出改变 DxDx。DD 的谱范数 ‖D‖op\lVert D\rVert_{\rm op} 等于单位输入上最大可能的输出变化，也就是 DD 的最大奇异值。因此，限制更新的谱范数，就是给一步更新对任意单位输入的影响设上限。

用动量 BB 估计下降方向时，一阶项是 ⟨B,D⟩F\langle B,D\rangle_F。对偶不等式给出下界 −‖B‖∗-\lVert B\rVert_*，也就是负的奇异值之和。取 D=−QD=-Q 恰好达到这个下界。

−Q∈argmin‖D‖op≤1⟨B,D⟩F.-Q\in\arg\min_{\lVert D\rVert_{\rm op}\le 1}\langle B,D\rangle_F.
⟨B,−Q⟩F=−‖B‖∗.\langle B,-Q\rangle_F=-\lVert B\rVert_*.

一次实际更新

设 Wt∈ℝm×nW_t\in\mathbb R^{m\times n}，Gt=∇Wℓ(Wt;ξt)G_t=\nabla_W\ell(W_t;\xi_t)。Jordan 仓库先把当前梯度加进动量 MtM_t，再把当前梯度与更新后的动量混合成 BtB_t，最后对 BtB_t 做 kk 轮 Newton–Schulz。

Mt=μMt−1+(1−μ)Gt,Bt=(1−μ)Gt+μMt.M_t=\mu M_{t-1}+(1-\mu)G_t,\qquad B_t=(1-\mu)G_t+\mu M_t.
Qt=NSk(Bt).Q_t=\operatorname{NS}_k(B_t).

默认动量系数为 0.95。关闭 Nesterov 式混合时取 Bt=MtB_t=M_t。权重更新分两项，先按比例缩小旧权重，再减去缩放后的矩阵方向。

Wt+1=(1−ηtλ)Wt−ηtsm,nQt.W_{t+1}=(1-\eta_t\lambda)W_t-\eta_t s_{m,n}Q_t.

Jordan 实现的 Nesterov 式混合发生在梯度求出之后，求梯度的位置是 WtW_t。第二篇的 EMA-Nesterov 在求梯度之前移动查询点。

Newton–Schulz 如何落到 GPU

GPU 实现用矩阵乘法近似极因子。先用 Frobenius 范数把输入缩到谱范数至多为 1，取 X0=Bt/(‖Bt‖F+ϵ)X_0=B_t/(\lVert B_t\rVert_F+\epsilon)。若行数大于列数，先转置，迭代后再转回。这样 Aj=XjXj⊤A_j=X_jX_j^\top 的边长取矩阵短边。

Aj=XjXj⊤,Xj+1=aXj+(bAj+cAj2)Xj.A_j=X_jX_j^\top,\qquad X_{j+1}=aX_j+(bA_j+cA_j^2)X_j.

把 XjX_j 的奇异值分解代进去，AjA_j 对应平方奇异值，AjXjA_jX_j 对应三次方，Aj2XjA_j^2X_j 对应五次方。因此每轮保留左右奇异向量，只把奇异值 zz 改为 az+bz3+cz5az+bz^3+cz^5。Jordan 版在 BF16 中通常做 5 轮，系数为 (3.4445,−4.7750,2.0315)(3.4445,-4.7750,2.0315)。用下方 FP32 示例处理 diag(12,1)\operatorname{diag}(12,1)，5 轮后的奇异值约为 0.856 和 0.700。理想极因子的两个奇异值都是 1。

下面用 NumPy 写出同一矩阵递推，以 FP32 演示。

import numpy as np


def muon_ns(matrix, steps=5):
    x = np.asarray(matrix, dtype=np.float32)
    transposed = x.shape[0] > x.shape[1]
    if transposed:
        x = x.T
    x = x / (np.linalg.norm(x) + 1e-7)
    for _ in range(steps):
        gram = x @ x.T
        x = 3.4445 * x + (-4.7750 * gram + 2.0315 * (gram @ gram)) @ x
    return x.T if transposed else x


def muon_step(weight, grad, momentum, lr, decay=0.0, beta=0.95):
    rows, cols = weight.shape
    momentum = beta * momentum + (1 - beta) * grad
    direction = muon_ns((1 - beta) * grad + beta * momentum)
    scale = np.sqrt(max(1.0, rows / cols))
    updated = (1 - lr * decay) * weight - lr * scale * direction
    return updated, momentum

参数分组、形状缩放与分片

参数分组。 Jordan 的训练配方把隐藏层权重矩阵交给 Muon，把输入嵌入、输出头、归一化参数和偏置交给 AdamW。卷积核可以把后三个维度展平，再用 Muon 更新。

形状缩放。 满秩极因子有 min(m,n)\min(m,n) 个值为 1 的奇异值，因此元素的均方根（RMS）是 1/max(m,n)1/\sqrt{\max(m,n)}。Jordan 版使用 sm,n=max(1,m/n)s_{m,n}=\sqrt{\max(1,m/n)}，把每行长度的均方根调到 1。Moonlight 使用 sm,n=0.2max(m,n)s_{m,n}=0.2\sqrt{\max(m,n)}，把元素 RMS 调到 0.2，以便和 AdamW 更新的量级对齐。实际的有限轮近似会让这个数值有所变化。

多卡训练。 Jordan 的 DDP 版把不同矩阵分给不同的卡更新，再收集更新后的权重。Moonlight 按数据并行组分片存储主权重和动量。每张卡先对本地梯度分片做动量更新，再为正交化聚合所需的整张矩阵。算出完整更新后，只应用属于本卡的切片，最后同步权重。跨卡聚合的原因是 XX⊤XX^\top 要用到整个矩阵的数据。

Moonlight 用这套配方训练了总参数 16B、每个 token 激活约 3B 参数的 MoE，共处理 5.7T tokens。

2. MONA：正交化前的梯度差

梯度差提供什么信息

考虑走了同样长的一步。损失曲面越弯，沿该方向的梯度通常变得越快。对全梯度，相邻两步的梯度差可用 Hessian 作用在这段位移上来近似。MONA 用已有的两次梯度做差来获取这一信号。每步换小批量也会改变梯度，所以先对差分做 EMA，再把它加进当前梯度。

先修正梯度，再走 Muon 流程

初始化 G0=A0=M0=0G_0=A_0=M_0=0。在 WtW_t 上计算小批量梯度 GtG_t，用 DtD_t 记录它与上一梯度的差，AtA_t 记录差分的指数移动平均。

Dt=Gt−Gt−1,At=βaAt−1+(1−βa)Dt.D_t=G_t-G_{t-1},\qquad A_t=\beta_a A_{t-1}+(1-\beta_a)D_t.

把 AtA_t 乘上修正强度 α\alpha 加回当前梯度，再更新矩阵动量 MtM_t。

G~t=Gt+αAt,Mt=μMt−1+G~t.\widetilde G_t=G_t+\alpha A_t,\qquad M_t=\mu M_{t-1}+\widetilde G_t.
Qt=NSk(Mt),Wt+1=(1−ηtλ)Wt−ηtsm,nQt.Q_t=\operatorname{NS}_k(M_t),\qquad W_{t+1}=(1-\eta_t\lambda)W_t-\eta_t s_{m,n}Q_t.

拿矩阵的一行举例。上一梯度是 (3,1)(3,1)，当前梯度是 (2,2)(2,2)，差分为 (−1,1)(-1,1)。若差分 EMA 原来是零，取 βa=0.5\beta_a=0.5 和 α=1\alpha=1，送入动量的这一行就变成 (1.5,2.5)(1.5,2.5)。取 α=0\alpha=0 时，递推回到该实验采用的 Muon 基线。

3. Muown：控制权重行范数

权重矩阵的谱范数为什么上涨

即使每一步的更新都有上限，多步更新也可能积累出很大的权重。谱范数变大有两种来源。各行可以变长，也可以变得更对齐。例如，两行单位向量互相垂直时，谱范数是 1。两行转到同一方向后，行长仍为 1，谱范数却变成 2\sqrt 2。

Lion 等用一个等式拆开这两种影响。把每行写成长度 ai=‖Wi‖2a_i=\lVert W_i\rVert_2 乘单位方向 UiU_i，再用对角矩阵 P=Diag(a/‖a‖∞)P=\operatorname{Diag}(a/\lVert a\rVert_\infty) 记录各行相对于最长一行的长度。

‖W‖op=‖a‖∞λmax(PUU⊤P).\lVert W\rVert_{\rm op}=\lVert a\rVert_\infty\sqrt{\lambda_{\max}(P UU^\top P)}.

等式右侧第一项是最大行长。第二项同时反映行方向有多对齐、各行相对有多长。在关闭权重衰减的 500M 实验中，最大行长和谱范数一起上涨，第二项在训练早期短暂变化后较平稳。作者又把每行长度固定在初始值，谱范数的系统性上涨随之消失。Muown 因此给每行长度单独安排一个更新分支。

每行分别更新长度和方向

5. 重尾噪声下的 Muon

动机：梯度噪声大时，怎样公平比较 Muon 和欧氏方法

训练中用一个小批量算出的梯度，等于真实梯度加上采样误差。如果偶尔出现特别大的误差，平方后它对方差的贡献会非常大。举个例子，假设误差的绝对值为 2k2^k 的概率与 4−k4^{-k} 成正比。每个量级对二阶矩的贡献相同，累加后发散。改算 1.5 阶矩，每个量级的贡献按 2−k/22^{-k/2} 衰减，累加后有限。Hübler、Pethick 与 Sra 用这种「较低阶矩有限」的假设研究 Muon。

比较前还要规定怎样算「接近驻点」。给更新矩阵 DD 一个单位步幅预算，当前梯度 GG 能带来的最大一阶下降量，就是梯度的对偶范数。欧氏方法用 Frobenius 范数限制 DD，对应的下降量是 ‖G‖F\lVert G\rVert_F。Muon 用谱范数限制 DD，对应的下降量是核范数 ‖G‖∗\lVert G\rVert_*。核范数把奇异值直接相加。如果一个梯度有 100 个大小相同的奇异值，它的核范数是 Frobenius 范数的 10 倍。此时达到相同的 ε\varepsilon，核范数提出了更严格的要求。

论文据此给两条路线设同一个目标。对 Muon 直接分析核范数驻点。对已有的欧氏保证，先求出需要多小的 Frobenius 范数，才能推出相同的核范数精度。比较的是达到这个目标所需的随机梯度调用次数。

模型假设与更新规则

设 F(W)F(W) 为总体损失，GtG_t 为在 WtW_t 处采到的随机梯度。用 Zt=Gt−∇F(Wt)Z_t=G_t-\nabla F(W_t) 表示采样误差。假设每步的随机梯度无偏，初始损失与下界相差至多 Δ1\Delta_1，并对每个查询点要求

𝔼‖Zt‖∗p≤σp,1<p≤2.\mathbb E\lVert Z_t\rVert_*^p\le\sigma^p,\qquad 1<p\le 2.

σ\sigma 是在核范数下量出的噪声尺度，pp 是所假设的有限矩阶数。p=2p=2 对应有界二阶矩。常数 LL 则限制真实梯度变化的速度。权重移动的谱范数乘上 LL，给出梯度变化的核范数上界。

理论里的 Muon 用 EMA 累积梯度，然后沿动量矩阵的精确极因子走一步。第一节中的有限步 Newton–Schulz 在工程上近似计算这一方向。

如果 MtM_t 等于真实梯度，线性近似的下降量就是 η‖∇F(Wt)‖∗\eta\lVert\nabla F(W_t)\rVert_*。实际用的是估出来的动量。令 et=‖Mt−∇F(Wt)‖∗e_t=\lVert M_t-\nabla F(W_t)\rVert_*，单步损失满足

F(Wt+1)−F(Wt)≤−η‖∇F(Wt)‖∗+2ηet+Lη22.F(W_{t+1})-F(W_t) \le -\eta\lVert\nabla F(W_t)\rVert_*+2\eta e_t+\frac{L\eta^2}{2}.

动量误差来自两处。每次采样都带噪声，平均更多梯度可以降低这部分误差。平均窗口越长，留下的旧梯度也越多，而参数已经走到了新位置。令 δ=1−β\delta=1-\beta，窗口长度的量级是 1/δ1/\delta。每步移动至多 η\eta，所以旧梯度的误差量级是 Lη/δL\eta/\delta。

随机噪声这部分更难。核范数有折角，难以直接用矩不等式来控制带符号的噪声和。比如矩阵 diag(1,0)\operatorname{diag}(1,0) 的第二个对角元加上 δ\delta 或 −δ-\delta，核范数都会从 1 变成 1+|δ|1+\lvert\delta\rvert。论文改在 Schatten-pp 范数下做平均。它把奇异值当成向量来取 pp 范数，允许用 pp 阶矩控制噪声累积。最后才用下式换回核范数，其中 d=min(m,n)d=\min(m,n)。

‖Z‖∗≤d1−1/p‖Z‖Sp.\lVert Z\rVert_*\le d^{1-1/p}\lVert Z\rVert_{S_p}.

p=1.5p=1.5 时，这一步的因子是 d1/3d^{1/3}。若从 Frobenius 范数换回核范数，因子是 d1/2d^{1/2}。Schatten-pp 在这两件事之间取得平衡。它能用已有的 pp 阶矩分析随机和，同时比 Frobenius 范数更接近核范数。算法本身一直用谱范数选方向，Schatten-pp 出现在证明中。

主要结论：维度代价从哪里省下来

对 EMA 加权后的噪声，主要误差项的量级是 σ(dδ)(p−1)/p\sigma(d\delta)^{(p-1)/p}。要让它小到 ε\varepsilon，可以取 δ\delta 的量级为 (ε/σ)p/(p−1)/d(\varepsilon/\sigma)^{p/(p-1)}/d。为了让旧梯度误差 Lη/δL\eta/\delta 也保持在 ε\varepsilon 量级，步长取 εδ/L\varepsilon\delta/L 量级。累加 TT 步后，初始损失差摊到每步是 Δ1/(ηT)\Delta_1/(\eta T)。这项也降到 ε\varepsilon 时，得到主导调用次数。

T=O(dΔ1Lε2(σε)p/(p−1)).T=O\left(d\frac{\Delta_1 L}{\varepsilon^2} \left(\frac{\sigma}{\varepsilon}\right)^{p/(p-1)}\right).

定理控制的是 TT 步梯度核范数的平均期望。等价地，从这些迭代点中均匀抽取一个点，它的梯度核范数期望至多为 ε\varepsilon。这里的一次调用是取一次随机梯度。每次更新在 GPU 上的成本需要另外计算。

一般结论：谱范数之外还有哪些选择

这套分析也适用于其他带动量的归一化最速下降。若对偶范数具有维度无关的 pp 阶一致光滑常数，就能直接在该范数下控制噪声和，主导调用次数中没有额外的维度因子。对矩阵，取 2≤r≤p/(p−1)2\le r\le p/(p-1)，用 Schatten-rr 约束更新，就落在这类保证内。
